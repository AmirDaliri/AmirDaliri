# Hi, I'm Amir 👋

### Senior iOS Developer | 10+ Years Experience | Founder @ As Apps Studio

I build native iOS applications with **Swift, SwiftUI, UIKit, Combine, RxSwift, StoreKit, and CI/CD**.

Over the last 10+ years, I have worked on fintech, banking, IoT, TV remote control, authentication, subscription-based, and consumer iOS products. My experience includes projects for **Bragi, KoçSistem, NEC Corporation of America, Conexus Credit Union, Coca-Cola, Total Oil, Tuborg**, and multiple App Store products.

I care about architecture, performance, maintainability, testing, release quality, and building apps that users can actually trust.

## What I Do

- Build production-grade iOS apps with **Swift, SwiftUI, UIKit, Combine, RxSwift, and AVFoundation**
- Design scalable architectures using **MVVM, MVVM-C, Clean Swift, and modular components**
- Develop reusable SDKs and packages with **Swift Package Manager**
- Improve code quality through **unit testing, profiling, debugging, and pull request reviews**
- Set up and maintain **CI/CD pipelines** with Bitrise, Fastlane, GitHub Actions, and GitLab CI
- Work with **StoreKit, In-App Purchases, subscriptions, Firebase, analytics, and deep links**
- Build device connectivity features using **WebSocket, discovery, pairing, casting, and remote-control flows**
- Lead development, mentor engineers, and support release planning

## As Apps Studio

I’m also building **As Apps Studio**, an independent iOS app studio focused on beautiful, privacy-first apps that simplify everyday digital life.

Current and upcoming products include:

- **Auth Kit** — 2FA codes, password vault, passkey storage, Face ID / Touch ID
- **AS Rock ID** — AI rock and mineral identification
- **AsRemote** — universal TV remote for Samsung, LG, Roku, and more
- **AS Cleaner** — duplicate photo detection, blurry finder, contact cleanup
- **CronCraft** — visual cron expression builder and decoder
- **Receipt Rescue** — AI receipt tracker for taxes and bookkeepers
- **ASvpn** — privacy-focused VPN app
