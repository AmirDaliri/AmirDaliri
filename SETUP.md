# Installation

Your GitHub profile repository should be named exactly `AmirDaliri`.

1. Copy `README.md`, `assets/`, and `.github/` into the root of that repository.
2. Commit and push the files to the `main` branch.
3. Open the repository's **Actions** tab and run **Generate contribution animation** once.
4. If GitHub asks, enable workflows under **Settings → Actions → General**.

The hero animation starts immediately. The contribution snake appears after the workflow creates the `output` branch.

## Motion included

- Slowly drifting ambient color fields
- Floating iPhone-inspired product card
- Rotating profile taglines with a blinking terminal cursor
- Subtle pulsing code icon and sparkles
- Animated contribution snake with light and dark variants
- Reduced-motion support for visitors who enable it in their operating system

The hero is self-contained in `assets/amir-hero.svg`; it does not depend on an animation server.
